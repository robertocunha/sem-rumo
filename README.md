# 🇧🇷 Sem Rumo — Roda Online

[🇺🇸 Read in English](#-sem-rumo--live-roda-english)

Página estática para transmitir ao vivo as rodas de samba do grupo Sem Rumo, do qual participo. Suporta streaming via YouTube ou Twitch (escolhido por parâmetro na URL), chat ao vivo embutido e botões de compartilhamento (WhatsApp, X, Telegram, copiar link). Construída em HTML/CSS/JS puro, sem dependências.

A ideia era transmitir uma das rodas — isso nunca chegou a acontecer na prática, mas a página funciona.

## Como usar

Basta abrir `index.html` no navegador. Pra ativar uma transmissão, use a URL com um dos parâmetros:

- `?yt=ID_DO_VIDEO` — transmissão via YouTube
- `?twitch=nome_do_canal` — transmissão via Twitch

## Stack

- HTML, CSS, JavaScript (vanilla, sem frameworks)

# 🇺🇸 Sem Rumo — Live Roda (English)

[🇧🇷 Ler em Português](#-sem-rumo--roda-online)

Static page built to livestream samba jam sessions ("rodas de samba") for Sem Rumo, a group I take part in. Supports YouTube or Twitch streaming (chosen via URL parameter), an embedded live chat, and share buttons (WhatsApp, X, Telegram, copy link). Built with vanilla HTML/CSS/JS, no dependencies.

The idea was to stream one of the sessions — that never actually happened, but the page works.

## How to use

Just open `index.html` in a browser. To activate a stream, use the URL with one of these parameters:

- `?yt=VIDEO_ID` — stream via YouTube
- `?twitch=channel_name` — stream via Twitch

## Stack

- HTML, CSS, JavaScript (vanilla, no frameworks)
